# 서울 실시간 도시데이터 웹앱

서울시가 공개하는 "실시간 도시데이터" API를 이용해서, 지역별 혼잡도·인구 예측·주변 문화행사를
한 화면에서 보여주는 아주 작은 웹페이지입니다.

## 이게 뭘 하는 앱인가요?

브라우저로 페이지를 열면:

1. 상단에 5개 지역 버튼(광화문·덕수궁 / 홍대 관광특구 / 강남역 / 여의도한강공원 / 성수카페거리)이
   있고, 원하는 곳을 누르면 그 지역 정보로 바뀝니다.
2. 지금 그 지역이 얼마나 붐비는지("여유/보통/약간 붐빔/붐빔")와 이유가 큰 카드로 보입니다.
3. 앞으로 12시간 동안 시간대별로 인구가 어떻게 변할지 막대그래프로 보여줍니다.
4. 그 지역 근처에서 하는 문화행사 목록을 종료일이 빠른 순서로 보여주고, 곧 끝나는
   행사에는 "곧 종료" 표시를 붙여줍니다.
5. 데이터는 페이지를 열 때마다(또는 다른 지역을 누를 때마다) 서울시 서버에 실시간으로
   물어봐서 가져옵니다. 화면 어딘가에 "언제 기준 데이터인지"가 작게 적혀 있습니다.

## 어떻게 실행하나요?

준비물: 컴퓨터에 [Node.js](https://nodejs.org)가 설치되어 있어야 합니다.

1. 이 폴더에 `.env` 라는 파일이 있는지 확인하세요. 없다면 새로 만들고 아래처럼 한 줄을
   적어주세요 (서울 열린데이터광장에서 발급받은 인증키를 넣습니다).

   ```
   SEOUL_API_KEY=발급받은_인증키
   ```

   ⚠️ 이 `.env` 파일은 절대 다른 사람과 공유하거나 인터넷(깃허브 등)에 올리면 안 됩니다.
   인증키가 그대로 노출되기 때문입니다. (이 프로젝트는 `.gitignore`에 이미 `.env`를
   등록해 놔서, git으로 기록을 남겨도 이 파일만은 자동으로 빠집니다.)

2. 터미널(명령 프롬프트)을 열고 이 폴더로 이동한 뒤 아래 명령을 입력합니다.

   ```
   node server.js
   ```

3. "서버가 실행되었습니다..." 라는 문구가 뜨면, 웹 브라우저에서 다음 주소를 엽니다.

   ```
   http://localhost:3000
   ```

4. 끝낼 때는 터미널에서 `Ctrl + C`를 누르면 서버가 종료됩니다.

주의: `index.html` 파일을 더블클릭해서 그냥 열면 동작하지 않습니다. 반드시
`node server.js`로 서버를 켠 다음, 브라우저 주소창에 `http://localhost:3000`을
입력해서 열어야 합니다. (서버가 인증키를 안전하게 숨긴 채로 서울시에 대신 물어봐주는
역할을 하기 때문입니다.)

## 폴더 안에 있는 파일들

| 파일 | 역할 |
|---|---|
| `index.html` | 실제로 브라우저에 보이는 화면(버튼, 그래프, 행사 카드 등)을 그리는 코드 |
| `server.js` | 로컬 서버. 화면 파일을 보내주고, 인증키를 숨긴 채 서울시 API를 대신 호출해줌 |
| `.env` | 서울시 API 인증키를 적어두는 파일 (git에 올라가지 않음) |
| `.gitignore` | git으로 기록을 남길 때 제외할 파일 목록 (`.env` 포함) |
| `fetch-citydata.js` | (참고용) 서울시 API를 한 번 호출해서 `citydata.json`이라는 스냅샷 파일로 저장해두는 스크립트. 지금 화면은 이걸 쓰지 않고 매번 실시간으로 부름 |
| `citydata.json` | 위 스크립트로 저장해둔 예전 스냅샷 데이터 (지금은 화면에서 사용하지 않음, 참고/디버깅용) |
| `analyze-structure.js` | (참고용) `citydata.json` 안에 어떤 항목들이 있는지 구조만 훑어보는 스크립트 |
| `서울시 주요 121장소 목록.xlsx` | 서울시가 제공하는 지역 이름 공식 목록 (새 지역을 추가할 때 정확한 이름을 찾는 용도) |

## 지금까지 한 일

1. 지역 하나(광화문·덕수궁)의 혼잡도, 12시간 인구 예측 그래프, 주변 문화행사를
   보여주는 기본 화면을 만들었습니다.
2. 화면을 다듬었습니다: 12시간 그래프에서 "지금" 표시가 중복되던 것을 고치고,
   막대그래프 옆에 예상 인구수(천 단위 콤마 포함)를 추가하고, 문화행사를 종료일이
   빠른 순으로 정렬하고 "곧 종료" 표시를 붙였습니다.
3. 저장된 파일(`citydata.json`)만 읽던 방식을 바꿔서, 페이지를 열 때마다 서울시
   API를 실시간으로 호출하도록 만들었습니다. 인증키는 브라우저가 아니라 서버(`server.js`)
   안에서만 쓰이도록 옮겼고, API가 느리거나 실패할 때를 대비해 "불러오는 중" 표시와
   "다시 시도" 버튼을 만들었습니다. 데이터가 언제 기준인지도 화면에 표시했습니다.
4. 지역을 5곳(광화문·덕수궁, 홍대 관광특구, 강남역, 여의도한강공원, 성수카페거리)으로
   늘렸습니다. 화면 위에 지역 선택 버튼을 나란히 두었고, 서울시 API는 한 번에 한
   지역씩만 부를 수 있어서 선택한 지역만 그때그때 불러오도록 했습니다. 한 번 불러온
   지역은 5분 동안 기억해뒀다가, 그 안에 다시 누르면 API를 다시 부르지 않고 바로
   보여줍니다.

## 실행 중 문제가 생기면

- 화면에 "데이터를 불러오지 못했습니다"가 뜨면 이유가 같이 적혀 있습니다.
  대부분은 `.env`에 인증키가 잘못 적혀 있거나, 인터넷 연결 문제, 또는 서울시
  API 서버가 잠깐 느린 경우입니다. "다시 시도" 버튼을 눌러보세요.
- "서버에 SEOUL_API_KEY가 설정되어 있지 않습니다"라는 메시지가 보이면, `.env`
  파일에 인증키를 제대로 적었는지, 서버를 껐다가 다시 켰는지 확인해주세요.
  (`.env`를 새로 고치면 `node server.js`를 다시 실행해야 반영됩니다.)
